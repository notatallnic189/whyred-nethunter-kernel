whyred nethunter kernel

A custom kernel for the Xiaomi Redmi Note 5 Pro, so the old thing can run Kali NetHunter properly. Maintained by hand, built by robots.  (source)

This is a stock LineageOS sdm660 kernel with a short list of changes that NetHunter needs and upstream does not ship. If you have a whyred on LineageOS 18.1 (or any Android 11 ROM close enough to it), you flash this and the NetHunter HID attacks, BadUSB gadget and external wifi monitoring work like on the officially supported devices. Nothing more, nothing less. Current release is v1.0.0, kernel version 4.4.302, actively maintained as of September 2026.

Download

Grab the AnyKernel3 zip from the v1.0.0 release page. Every zip is built by GitHub Actions straight from the sources in the repo, so what you flash matches the commit you can read. No re-uploads, no "trust me" zips.

What is actually different from stock

Config changeWhy
CONFIG_USB_CONFIGFS_F_HID=yHID gadget, needed for DuckHunter style keystroke injection over OTG
CONFIG_USB_CONFIGFS_F_FS=yfunctionfs, plumbing for the NetHunter USB gadget
CONFIG_MODULES=y + unloadout-of-tree modules like the rtl8812au driver can load
ANDROID_PARANOID_NETWORK removedchroot and proot tools can open sockets without AID_INET
CONFIG_LOCALVERSION="-Nethunter-whyred"uname -a tells you what you are running

Full list in the README on GitHub.

External wifi: rtl8812au

The repo also builds the aircrack-ng rtl8812au module, signed with the same key as the kernel, so you get real monitor mode and packet injection from a cheap ALFA adapter plugged in over OTG. The module zip ships next to the kernel zip on the release page. Flash kernel first, then the module, then reboot once.

Install, short version

  1. Unlock your bootloader and install LineageOS 18.1 (there are a hundred guides, the XDA one below is fine)
  2. Download the kernel zip (and the module zip if you have a 8812au adapter)
  3. Reboot to recovery, flash the zips, reboot
  4. Install the NetHunter app and chroot from the official Kali images as usual
The long version with pictures, magisk notes and rollback steps lives in the XDA thread. Questions go there too, or to the Telegram channel.

Known limitations

  • The internal WCN3980 wifi chip cannot do monitor mode. Firmware limitation, same on every whyred kernel ever built, so do not ask, use an external adapter.
  • Android 9 and 10 ROMs are not supported, the kernel expects the Android 11 userspace. GSI results vary and I do not test them.
  • VoLTE on some custom ROMs needs the ROM's own patches, unrelated to this kernel.

Why not the 2020 kernel

The old Team-420 whyred kernel was built against Android 9 era sources and has not been touched in years. This one is based on the LineageOS 18.1 sdm660 tree, builds in CI on every release, and includes the module work the old one never had. If you are on old ROMs, the old kernel is still a fine choice; if you moved to Android 11, this is the maintained option.
